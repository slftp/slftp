Usage: <cmd> <srcsite> <dstsite> [rank] [--allow|--block|--reset] [--affil-target] [--c1] [--c2] [--sw1] [--sw2] [-b/--back] [-a/--apply] [-f/--affil] [-n/--noaffil] [-l/--lock]
Description: Sets routes between src and dst sites and configures their cbftp transfer policies.

Normal positional parameters (mandatory/optional):
<srcsite>
  Site name or wildcard * for all 
<dstsite>
  Site name or wildcard * for all
[rank]
  Optional. Rank from 1 to 9 (default: 9 for allow, 0 for block/reset). Use 0 to remove routes in slftp.

Named parameters (optional cbftp policies):
--allow
  Configure cbftp to only allow transfers between the sites (sets policies to BLOCK, default behavior).
--block
  Explicitly block transfer direction between the sites in cbftp (sets policies to ALLOW).
--reset
  Reset transfer exceptions between the sites in cbftp.
--affil-target
  Applies target policies specifically to affiliate releases (transfer_target_affil_policy).

Named parameters (optional wildcards filters):
--c1 XX
  Source sites country
--c2 XX
  Destination sites country 
--sw1 XX
  Source ftpd softwares 
--sw2 XX
  Destination ftpd softwares

XX for countries is for example .fr, .hu, ...
XX for ftpd softwares can be GLFTPD, IOFTPD or DRFTPD

-a/--apply
  Really apply changes. For safety when using wildcards the changes are not
  applied if you don't specify that you want to apply the changes. If omitted 
  it just displays what changes would be done.
-b/--back
   Add back route from dest to source aswell
-f/--affil
   This route is only enabled when the source has the release group in its affils list.
-n/--noaffil
   This route is only enabled when the source has the release group NOT in its affils list.
-l/--lock
   Lock the given speed rank, so that a new speed will not be calculated.

Examples:
Allow transfers from SITE1 to SITE2 (exclusively):
<cmd> SITE1 SITE2 --allow
Reset all exceptions between all sites (with back routes) and apply changes:
<cmd> * * --reset -b -a
Explicitly block SITE1 from transferring to SITE2:
<cmd> SITE1 SITE2 --block
Allow affiliate target transfers specifically:
<cmd> SITE1 SITE2 --allow --affil-target
